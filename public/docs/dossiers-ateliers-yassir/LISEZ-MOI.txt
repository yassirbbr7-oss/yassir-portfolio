INSTALLATION DANS LE PORTFOLIO EXISTANT
1. Copier tous les PDF des sept dossiers dans public/docs/ (sans sous-dossiers).
2. Remplacer api/index.php par le fichier inclus dans api/.
3. Faire un commit puis un push.
4. Consulter chaque lien après le redéploiement.

Ce ZIP est un complément au portfolio existant, pas un site complet.
Conserver les autres fichiers de votre dépôt.
